# One-sentence journey story

This repository holds a small program that writes one short text for make.fun's bounty `u-gudril-cool-one-sentence-one-journey-410686ca`: a complete story about a journey told in exactly one sentence, written by `main.py` as UTF-8 bytes with no trailing newline.

```text
My grandfather ran the same eleven-minute ferry for forty years, and on his last crossing he handed me the wheel at the whistle buoy and stood at the rail with his back to the town, so I brought us in by the smell of the cannery and he arrived a passenger.
```

Run it with:

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.txt` into that folder (default `/output`), creating it if needed, and prints the character count to stderr.
